# Pacman WebUI Game

A classic Pacman game implemented in HTML5, CSS, and JavaScript.

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use arrow keys to move Pacman around the maze
4. Collect all yellow dots to win
5. Avoid the ghosts (red, pink, cyan, orange)
6. Collect power pellets (large yellow circles) to temporarily make ghosts scared and edible
7. You have 3 lives - lose one each time a ghost catches you

## Game Features

- Classic Pacman gameplay with maze navigation
- Four AI-controlled ghosts with different colors
- Power pellets that make ghosts vulnerable
- Score system (10 points per dot, 50 per power pellet, 200 per ghost)
- Lives system
- Win/lose conditions
- Pause functionality
- Responsive design for mobile devices

## Controls

- **Arrow Keys**: Move Pacman (Up, Down, Left, Right)
- **Start Game Button**: Begin a new game
- **Pause Button**: Pause/resume the current game

## Technical Details

- Pure HTML5/CSS/JavaScript implementation
- Canvas-based rendering
- No external dependencies
- Responsive design
- Game loop with collision detection
- Simple ghost AI with random movement patterns

## File Structure

- `index.html` - Main game page
- `style.css` - Game styling and responsive design
- `script.js` - Game logic, rendering, and controls

Enjoy playing Pacman!
